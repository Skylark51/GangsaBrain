II-1-01 · THINKING ARCHIVE

지질 시대의 환경과 생물

화석의 정의를 암기하는 데서 끝내지 않고, 문제를 본 순간 어떤 분류를 먼저 수행하고 어떤 사건열과 시대 정보를 자동으로 호출하는지를 기록한다. 문항별 풀이를 누적하면서 반복되는 반응을 공통 알고리즘으로 승격한다.

현재까지 확인된 반응 모듈

화석 유형 판별생물 이름이나 사진을 보면 표준 화석인지 시상 화석인지 먼저 구분한다.
화석 형성 사건열순서 배열 문제임을 확인하는 즉시 죽음·매몰·화석화·퇴적·노출의 흐름을 호출한다.
지층의 시대 제한시상 화석으로 지층의 시대를 같다고 판단하지 않고 위아래 표준 화석으로 가능한 시대를 제한한다.
분포 그래프 해석생존 기간과 지리적 분포 면적을 축으로 보고 표준 화석과 시상 화석의 조건을 연결한다.
IS2-GEO-FOSSIL-001

산호 화석의 조건을 판단하는 문제

시상 화석조건 판단사진 자료
문항 구조

산호 화석 사진을 제시하고, 이러한 화석이 되기 위한 조건으로 생존 기간·분포 면적·개체 수의 특성을 고르는 문제.

보기: 생존 기간이 짧다 / 분포 면적이 좁다 / 개체 수가 많다.

최초 인식

산호를 보자마자 개별 보기부터 읽지 않는다. 먼저 산호가 시상 화석이라는 분류를 호출한다.

실제 사고 순서

  1. 시상 화석인가, 표준 화석인가?
  2. 시상 화석은 환경을 알려 준다.
  3. 같은 환경이 유지되는 동안 오래 생존할 수 있으므로 생존 기간은 길다.
  4. 특정 환경에서만 살기 때문에 지리적 분포 면적은 좁다.
  5. 화석으로 잘 발견되려면 개체 수는 많아야 한다.

선지 처리

  • ㄱ 생존 기간이 짧다 → 거짓
  • ㄴ 분포 면적이 좁다 → 참
  • ㄷ 개체 수가 많다 → 참
정답 판단: ㄴ, ㄷ. 문제를 푸는 출발점은 산호의 모양을 자세히 관찰하는 것이 아니라, 산호를 시상 화석으로 분류하는 것이다.

추출 알고리즘 A · 생물 사진이 나온 화석 문제

  1. 생물 확인 → 생물의 세부 외형보다 이름과 대표성을 먼저 본다.
  2. 화석 유형 분류 → 표준 화석 / 시상 화석.
  3. 제공 정보 결정 → 표준 화석은 시대, 시상 화석은 환경.
  4. 조건 자동 연결 → 시상 화석은 긴 생존 기간·좁은 분포, 표준 화석은 짧은 생존 기간·넓은 분포.
  5. 그 다음에 보기를 읽으며 조건과 대조한다.
IS2-GEO-FOSSIL-002

화석이 생성되는 순서를 배열하는 문제

과정 배열화석의 정의사건열 호출
문항 구조

생물의 죽음, 매몰과 화석화, 계속된 퇴적, 융기·침식에 따른 노출을 나타낸 네 그림의 순서를 배열한다.

① 생물체가 죽거나 생물의 흔적이 남는다.
↓
② 유해 또는 흔적이 퇴적물에 빠르게 묻히고 화석화 작용을 받는다.
↓
③ 위에 퇴적물이 계속 쌓이며 지층 속에 보존된다.
↓
④ 지층이 융기하고 침식되어 화석이 지표에 드러난다.

속도가 느려지는 접근

네 그림을 하나씩 독립적으로 관찰하고 그때마다 무슨 장면인지 해석하면 정답은 찾을 수 있지만 반응 시간이 길어진다.

숙련된 접근

‘화석 생성 순서를 묻는다’는 사실을 인지하는 순간, 이미 알고 있는 사건열을 먼저 떠올린 뒤 각 그림을 그 자리에 배치한다.

그림 배치

제시된 그림에서는 ㄴ → ㄷ → ㄹ → ㄱ의 순서가 된다.

선행 오개념 제거 · 화석은 반드시 뼈일 필요가 없다. 화석은 과거 생물의 유해 또는 흔적이다. 뼈와 껍데기뿐 아니라 발자국, 기어간 자국, 배설물, 굴과 같은 생활 흔적도 화석이 될 수 있다.
과정 알고리즘의 적용 범위 ‘생물체의 죽음 → 매몰’은 유해 화석을 설명할 때의 기본 흐름이다. 발자국이나 배설물과 같은 흔적 화석에서는 생물의 죽음이 반드시 선행할 필요가 없다. 따라서 더 넓은 공통 흐름은 유해 또는 흔적의 생성 → 빠른 매몰 → 보존·화석화 → 추가 퇴적 → 융기·침식·노출이다.

추출 알고리즘 B · 과정 순서 배열 문제

  1. 문제의 요구가 ‘순서’임을 먼저 확인한다.
  2. 그림을 읽기 전에 해당 현상의 표준 사건열을 머릿속에 호출한다.
  3. 각 그림은 독립적으로 해석하지 않고 사건열의 빈칸에 끼워 넣는다.
  4. 첫 사건과 마지막 사건을 먼저 고정한 뒤 중간 단계를 배열하면 판단량이 줄어든다.
IS2-GEO-FOSSIL-003

고사리 화석과 위아래 표준 화석으로 지층의 시대를 제한하는 문제

지층 대비표준·시상 화석분포 그래프
문항 구조

서로 다른 지층에서 고사리 화석 A와 B가 발견되고, 위아래 지층에는 방추충·삼엽충·공룡 화석이 제시된다. 매머드·공룡·산호 화석의 생존 기간과 지리적 분포 면적을 그래프 ㄱ~ㄷ과 연결한다.

1. 같은 고사리라는 이유로 시대를 같게 두지 않는다

고사리는 시상 화석이며 현재에도 존재한다. 따라서 A와 B에서 모두 고사리가 발견되었다는 사실만으로 두 지층이 같은 시대에 형성되었다고 판단할 수 없다.

2. 위아래 표준 화석으로 범위를 제한한다

  • A 고사리의 위에는 방추충, 아래에는 삼엽충이 있으므로 A는 대략 고생대의 범위로 제한된다.
  • B 고사리의 위아래에는 공룡 화석이 있으므로 B는 중생대의 범위로 제한된다.

3. 시대가 맞지 않는 후보를 제거한다

매머드는 신생대의 대표 생물이다. 따라서 공룡 화석으로 둘러싸인 중생대 지층 사이에 들어갈 수 없다.

4. 분포 그래프를 유형과 연결한다

산호는 시상 화석이므로 생존 기간이 길고 지리적 분포 면적은 좁다. 따라서 산호는 그래프 ㄱ에 해당한다.

화석시대·유형 판단그래프
매머드 X신생대, 비교적 짧은 생존 기간과 넓은 분포ㄷ
공룡 Y중생대에 널리 분포하며 매머드보다 긴 생존 범위ㄴ
산호 Z시상 화석, 긴 생존 기간과 좁은 분포ㄱ
최종 연결: X-ㄷ, Y-ㄴ, Z-ㄱ. 동일한 시상 화석의 존재는 지층의 동시성을 보장하지 않으며, 시대 판단은 표준 화석과 층서 관계를 이용한다.

추출 알고리즘 C · 여러 지층의 시대를 비교하는 문제

  1. 공통 화석 확인 → 그 화석이 표준 화석인지 시상 화석인지 먼저 판별한다.
  2. 시상 화석이면 동시성 판단에서 제외 → 같은 생물이 있다고 같은 시대라고 두지 않는다.
  3. 위아래 표준 화석 확인 → 각 지층이 들어갈 수 있는 시대 범위를 위와 아래에서 동시에 제한한다.
  4. 대표 생물의 시대와 대조 → 고생대·중생대·신생대가 맞지 않는 후보를 제거한다.
  5. 그래프 축 해석 → 생존 기간과 지리적 분포 면적을 화석 유형의 조건과 연결한다.

현재까지의 공통 반응식

생물·화석 제시 → 화석 유형 분류 → 제공 가능한 정보 결정 → 시대 또는 환경 판단

과정 배열 요구 → 표준 사건열 호출 → 그림을 사건열에 배치

지층 대비 → 시상 화석 배제 → 위아래 표준 화석으로 시대 범위 제한 → 시대 부적합 후보 제거

이 문서는 문항이 추가될 때마다 개별 풀이보다 반복되는 판단 순서를 우선 갱신한다.
